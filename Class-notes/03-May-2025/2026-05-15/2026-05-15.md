# Setup Before Registering a Domain
enabling the API so we can use the GCP service Cloud Domain
1. navigate to searchbar > enter domain
1. Click Cloud Domain
1. Click continue
1. Click enable
1. Click view terms of service
1. Click accept

# Registering a Domain

**Search Domain**
1. Click Register Domain
1. Search for domain name
1. Select Domain Name
1. Click continue

**DNS Configuration**
1. Select `Use Cloud DNS`
1. click continue

**Privacy Protection**
1. Select `limit your info available to the public`

**Privacy Protection**
1. fill out contact info

Finish the registration <br>
Now your domain has been registered <br>
Repeat the same process to register an second domain <br>

# End Result
We have two domain names registered

# Creating Instance Group

1. leave everything as default and click configure

**Front-end configuration**
1. enter a name
1. protocol https
1. port 443
1. use certificate map
1. enable API
1. select `use classic certificate`

**create a certificate**
1. select create a new certificate
1. enter a name
1. select create google-managed certificate
1. paste domain name we bought for domain 1
1. set `http keepalive timeout` to 20 seconds

**Front-end configuration**
1. click done

**back-end configuration**
1. select `pocari-backend`
1. select a create a backend service

**create a backend service**
1. select any health check
