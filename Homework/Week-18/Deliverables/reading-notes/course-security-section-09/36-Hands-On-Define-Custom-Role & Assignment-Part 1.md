ways custom roles can be creates/defined
1. Combined permission from ultiple pre-define role
2. Remove permission from pre-defined role. 
- example, we have an predefined role like compute admin; we dont need all of the permissions from the predefined role. The unneccsary permissions can get removed. Therefore we created an custom role
3. Add more permissions to an pre-defined role to create an custom role
4. Add a list of permissions
