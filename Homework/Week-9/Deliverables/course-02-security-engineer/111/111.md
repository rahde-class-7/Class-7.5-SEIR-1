# LAB 1
# OBJECTIVE
1. Create VM with nginx installed
2. Create an unmanaged instance group from virtual machine
3. Create a load balancer with unmanaged instance group as backend

# Phase 1. Create VM with nginx installed
The virtual machine is intended for an unmanaged instance group. therefore, an instance template is not needed in this configuration

1. Click create VM
1. enter name
1. select series n1
1. firewall allow http
1. management > automation > startup script
1. enter script
1. click create
1. copy external ip and paste it in the browser

# Phase 2. Create an unmanaged instance group

1. Click create instance group
1. enter name
1. select network
1. select VM
1. click create

# Phase 3. Create a load balancer

1. Click create load balancer
1. internet facing
1. global https
1. enter name
1. select backend
1. create backend service
1. select instance group
1. port number 80
1. create health check
1. click create

# validation
find external ip of the load balancer and paste it in the browser
