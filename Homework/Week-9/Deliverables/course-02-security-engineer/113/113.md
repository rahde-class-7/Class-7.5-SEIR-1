# Phase 1. IP Address

1. activated cloudshell
1. navigate to website ipify
1. copy and paste api url in the browser
1. in cloudshell
&nbsp;&nbsp;&nbsp;&nbsp; 1. curl < ipify api url >
&nbsp;&nbsp;&nbsp;&nbsp; 1. make an note of the ip address
&nbsp;&nbsp;&nbsp;&nbsp; 1. make an note of the local machine ip address
1. in terminal
&nbsp;&nbsp;&nbsp;&nbsp; 1. curl < cloudshell ip >

## validation
1. click on the policy we created
1. pasted ip of load balancer in browser and refresh the page

Notes: takes a couple of minutes for the policy to take effect

# Phase 2. Add an second rule

1. Click add rule
1. enter a description
1. for match enter cloudshell ip address
1. action allow
1. priority 900
1. click add

# Phase 3. Removed an rule
1. Click on rule whos match is 0.0.0.0/0
1. removed the rule

# Phase 4. Add an second rule

1. Click add rule
1. enter a description
1. for match enter local ip address
1. action deny
1. priority 1000
1. click add

## validation
1. click on the policy we created
1. pasted ip of load balancer in browser and refresh the page
1. curl ip address of the load balancer from cloudshell

Notes: takes a couple of minutes for the rule to take effect
